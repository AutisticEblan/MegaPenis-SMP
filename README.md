# MegaPenis-SMP

Сборка модов для сервера. Репозиторий = папка `mods`.

## Как делать сасалку модов

1. Зелёная кнопка **Code** → **Download ZIP**.
2. Распакуй ZIP в папку модов своей сборки: `versions\<сборка>\mods`.
4. Для обновления запускай `CONTROLS\PULL.bat`. Он сам скачает свежий ZIP и обновит моды.

Твои личные моды при обновлении не потеряются — они сохраняются в `CONTROLS\_backup`.

## Для крутого админа

1. Зелёная кнопка **Code** → **Download ZIP**.
2. Распакуй ZIP в папку модов своей сборки: `versions\<сборка>\mods`.
3. Запусти `CONTROLS\PUSH.bat` — он сам всё настроит:
   - если Git не установлен, предложит скачать и установит автоматически;
   - создаст SSH-ключ и скопирует его в буфер обмена — отправь его мне для выдачи доступа;
   - инициализирует репозиторий и отправит моды на сервер.
3. `CONTROLS\PULL.bat` — скачать моды с сервака.
4. `CONTROLS\PUSH.bat` — отправить моды на сервар.
