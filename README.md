# MegaPenis-SMP

Сборка модов для сервера. Репозиторий = папка `mods`.

## Для пользователей (без Git)

Git не нужен.

1. Открой репозиторий на GitHub → зелёная кнопка **Code** → **Download ZIP**.
2. Распакуй ZIP. Внутри будет папка с модами и папкой `CONTROLS`.
3. Содержимое (все `.jar`, `CONTROLS`, `README.md`) перенеси в папку модов своей сборки: `versions\<сборка>\mods`.
4. Для обновления запускай `CONTROLS\PULL.bat`. Он сам скачает свежий ZIP и обновит моды.

Твои личные моды при обновлении не потеряются — они сохраняются в `CONTROLS\_backup`.

## Для админов (с Git)

1. Скачай ZIP репозитория (как игрок) и распакуй в папку модов.
2. Запусти `CONTROLS\PUSH.bat` — он сам всё настроит:
   - если Git не установлен, предложит скачать и установит автоматически;
   - создаст SSH-ключ и скопирует его в буфер обмена — отправь его админу для выдачи доступа;
   - инициализирует репозиторий и отправит моды на сервер.
3. `CONTROLS\PULL.bat` — обновить моды.
4. `CONTROLS\PUSH.bat` — отправить моды на сервер.
